**St Mary's Urban Mobility Hub**

A website developed using HTML, CSS and JavaScript to help students explore transport options across London, estimate journey costs and check London Underground service updates.

**Features:**
- Homepage displaying different transport options, including buses, trains, bicycle hire and walking.
- Journey cost estimator for trains, buses and bicycle hire.
- Train fare estimation based on starting zone, destination zone and peak or off-peak travel times.
- Bus cost calculation based on distance travelled in miles.
- Bicycle hire cost calculation based on distance travelled in kilometres.
- Live London Underground status updates retrieved using the TfL API.
- Service status indicators using different colours to highlight delays and severe disruptions.
- Automatic refresh of Underground service updates every 10 seconds.
- Navigation between the homepage, fare estimator and service updates pages.
- Responsive webpage structure using HTML and CSS.

**Technologies Used:**
- HTML for webpage structure and content.
- CSS for styling and page layout.
- JavaScript for interactive features and cost calculations.
- TfL API for retrieving London Underground service status information.
- Fetch API for requesting and processing live transport data.
